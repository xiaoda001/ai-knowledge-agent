# 知识库上传测试样例

这些文件内容均为虚构资料，仅用于测试自动识别、上传、解析、索引和问答。

## 建议准备

在知识库页面分别准备两个测试知识库，并填写用途说明：

- **电商规则**：电商平台政策、订单、退款、退货、物流和客服处理。
- **人事制度**：员工考勤、排班、年假、病假、调休和内部管理。

用于上传的账号需要加入这两个知识库，并具有“上传知识文档”权限。

## 样例与预期

- `电商平台售后规则-测试.md`：应优先推荐“电商规则”。
- `员工休假与考勤制度-测试.txt`：应优先推荐“人事制度”。
- `跨主题客服培训-测试.md`：故意同时涉及售后和排班，系统应显示推荐并要求确认。
- `IT账号与设备支持规范-测试.md`：应优先推荐“IT 服务台”；包含故障分级表和处理时限。
- `差旅与费用报销规范-测试.txt`：应优先推荐“财务与采购”；包含报销期限、审批要求和超标处理。
- `产品保修与维修手册-测试.md`：应优先推荐“产品支持”；可测试型号、保修期限和维修条件的精确检索。

入库完成后，可以使用各文件末尾列出的测试问题检查检索结果。知识库说明、文件标题和已收录资料会影响推荐结果，因此首次上传时请核对推荐库是否合理。

## 新增知识库建议

为测试更多分类场景，可按资料主题另建“IT 服务台”“财务与采购”“产品支持”知识库，并在知识库说明中写明对应职责。不同资料包含表格、编号规则、条件例外和相似数字，适合检查解析与答案是否准确引用上下文。
